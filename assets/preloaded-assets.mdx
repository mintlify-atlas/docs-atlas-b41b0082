Console ships with over 200 Unity AssetBundle files stored in the `ServerData/` directory. Each file is a self-contained bundle that can hold one or more named 3D objects — characters, weapons, environments, visual effects, and interactive props — ready to be spawned into any Gorilla Tag room without any additional downloads. The categories below cover every bundle included in the current release, organized by type to help you find the right asset quickly.

<Tip>
  The bundle name you pass to `asset-spawn` must exactly match the filename as it appears in the `ServerData/` directory — including any spaces or special characters. For example, to spawn the skibidi toilet bundle the command is `asset-spawn "skibidi toilet" <Name> <Index>`.
</Tip>

<Note>
  The `Index` parameter in `asset-spawn` is a caller-assigned integer (e.g. `0`, `1`, `2`) that you choose at spawn time. You use that same number in every subsequent command — `asset-setposition`, `asset-setanchor`, `asset-destroy`, and so on — to target that specific spawned object.
</Note>
