The `exec-safe` command is Console's bridge to Lua scripting. It allows a Console administrator to remotely trigger a named Lua script that has been pre-registered with the SafeLua engine on the receiver's client. Rather than sending raw code over the network, `exec-safe` uses a name-based lookup: the receiver's mod holds the actual script logic, and the admin simply invokes it by name. This design keeps arbitrary code off the wire while still giving mod developers a flexible, scriptable execution hook on the receiver's end.

<Info>
  SafeLua is a sandboxed Lua execution environment. It exposes a safe subset of Lua capabilities, preventing scripts from accessing unauthorized system resources or game internals beyond what the sandbox explicitly permits. This is the security boundary that makes remote script execution viable in a shared game environment.
</Info>

---

## `exec-safe`

```
exec-safe [Lua Script Name]
```

Runs a lua script in SafeLua by name on the receiver.

<ParamField path="Lua Script Name" type="string" required>
  The name of the Lua script as it was registered with SafeLua on the receiver's Console instance. This must exactly match the registration name; Console performs a name-based lookup to find and run the script.
</ParamField>

<Warning>
  You **cannot** send arbitrary Lua code through `exec-safe`. Only scripts that have been pre-registered on the receiver's Console instance can be executed. Attempting to invoke an unregistered script name will result in a no-op on the receiver's end.
</Warning>

<Note>
  Scripts must be registered on the receiver's Console instance before they can be executed remotely. Registration happens at mod startup on the receiver's side — the admin-side call simply names the script to run.
</Note>

## Workflow

Before an admin can trigger a script, the receiver's mod must have it registered with SafeLua. Once that is in place, triggering it is a single command call.

### 1. Define and Register the Script on the Receiver's Mod

In your receiver-side BepInEx mod, register a Lua script with SafeLua during initialization. The name you register here is the name you will pass to `exec-safe`.

```lua
-- Example SafeLua script: "greetUser"
notify("Hello from a Lua script!")
```

### 2. Trigger the Script via exec-safe

Once the receiver is running with the script registered, an authorized admin can invoke it remotely by name:

```csharp
Console.ExecuteCommand("exec-safe greetUser");
```

Console will send the `exec-safe greetUser` command to the target receiver. Their client looks up `greetUser` in the SafeLua registry and executes it inside the sandbox.
